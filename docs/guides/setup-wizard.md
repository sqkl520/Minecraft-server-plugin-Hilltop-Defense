# 8 步部署向导：边角规则与子命令详解

本文由 README 对应章节下移而来，README 侧保留摘要与入口链接。

## 向导的竞技场认定与自动入队

进入**竞技场世界**（见 `deploy-stages-1-2.md` 的阶段 2.5），执行：

```
/hilltop setup
```

> 向导会**按你当前所在的世界**自动认定要部署的竞技场（支持任意竞技场，不限默认场），因此哪怕该竞技场
> 还没配置核心、尚无运行实例，也能直接开始部署。若你不在任何已配置的竞技场世界里（见 `arenas.yml`），
> 向导会提示 `你当前不在任何已配置的竞技场世界里` 并告诉你如何传送进去。部署走完第 8 步后，该竞技场会
> **自动放进启用队列**（`enabled: true` 时），加载完成后玩家即可 `/hilltop join`、管理员可 `/hilltop start`；
> 若该场在 `arenas.yml` 中为 `enabled: false`（`arena2` / `arena3` 默认如此），请先改为 `true` 并**重启服务器**
> （启动时自动入队）。注意 `/hilltop enable <竞技场>` **无法绕过该开关**——`enabled: false` 的场用 enable 会被拒绝；
> 手动入队仅适用于已部署且 `enabled: true` 的场。

8 步逐步骤表（与 README 摘要同源，此处为完整版）：

| 步骤 | 内容 | 操作 |
|------|------|------|
| 1/8 确认世界 | 显示当前所在世界名 | 点击 [确认] |
| 2/8 设置核心 | 站在村庄核心位置（玩家重生点） | 点击 [设为核心] |
| 3/8 生成点管理 | 玩家出生点 + 怪物刷怪点（两套独立坐标，**各必须至少 1 个**） | 走到每个位置，点击聊天栏 [添加当前位置]（出生点）/ [添加刷怪点]（刷怪点）；点 [打开生成点总览] 进入枢纽界面（计数/状态一览、可进两个子管理界面查看/删除）；在总览中点唯一的 [完成]（两套点都配好才能离开本步） |
| 4/8 节点管理 | 能量节点（重生锚）的注册（**至少 1 个**） | 先在地图上**放置重生锚方块**，走到旁边点击 [添加节点]（无法右键注册的节点会有提示）；点 [继续] 进入下一步 |
| 5/8 村民放置 | 待保护村民的位置（**全部阵亡 = 游戏失败**，**至少 1 个**） | 走到目标位置点击 [添加村民] —— 登记处会**立刻生成一只不可伤害的预览村民**（头顶显示编号，仅本步可见，离开本步即清除）；或点 [打开村民管理] 打开 GUI 查看/删除（GUI 内 [显示粒子] 可黄色预览全部村民位置）；完成后点 [完成] |
| 6/8 商店位置 | 村民商店 NPC 的摆放位置（**必填，未设置无法完成部署**） | 站在目标位置点击 [设置商店位置]；[显示粒子] 可金色预览当前位置；点 [清除商店位置] 可删除重设，[继续] 进入下一步 |
| 7/8 配置预览 | 总览核心/出生点/刷怪点/节点/村民/人数/波次 | GUI 中点 [确认保存] |
| 8/8 部署完成 | 显示启动入口 + 启用指引（自动入队结果，未自动启用时附 [启用竞技场] 按钮） | 点击聊天栏的 /hilltop start |

## 强制项与回改步骤

> **强制项**：玩家出生点、怪物刷怪点、村民、商店位置四者缺一不可。缺少任意一项时点 [确认保存] 会被拒绝，并自动跳回对应步骤补齐。

> **回改已过步骤**：`/hilltop setup goto <步骤>`（1-8）可跳回任意步骤重新操作。

## 粒子配色（五类点位一色一义）

> **粒子配色**：所有点位预览统一使用彩色光柱 + 环绕螺旋，五类点位一色一义 —— 玩家出生点=**绿**、怪物刷怪点=**红**、能量节点=**蓝**、待保护村民=**黄**、商店=**金**。向导第 3 步的两套点管理 GUI、第 4 步节点 GUI、第 5 步村民 GUI、第 6 步商店按钮，以及 `/hilltop deploy showparticles` 与竞技场管理 GUI（`/hilltop manage`）的 Shift+左键预览全部遵循此配色。

## 部署向导子命令 (`/hilltop setup`)

向导进行中可用（一般通过聊天栏可点击按钮触发，无需手动输入）：

| 命令 | 说明 |
|------|------|
| `confirm-world` | 确认游戏世界（步骤 1） |
| `confirm-core` | 将当前位置设为村庄核心（步骤 2） |
| `addspawn` | 将当前位置添加为玩家出生点（步骤 3，反馈带序号） |
| `overview` | 打开生成点总览 GUI（步骤 3 枢纽：两套点计数/状态 + 两个子管理界面入口 + 唯一 [完成]） |
| `spawngui` | 打开玩家出生点管理 GUI（步骤 3，直达；界面内 [返回总览] 回到总览） |
| `spawns-done` | 完成生成点设置（步骤 3，仅向后兼容保留；与总览 [完成] 同一逻辑） |
| `addmobspawn` | 将当前位置添加为怪物刷怪点（步骤 3，反馈带序号） |
| `mobspawngui` | 打开怪物刷怪点管理 GUI（步骤 3，直达；界面内 [返回总览] 回到总览） |
| `confirm-nodes` | 确认能量节点设置（步骤 4，需至少 1 个节点） |
| `rescan` | 已废弃（只回提示；请用 [打开节点管理] GUI） |
| `villagers-done` | 完成村民放置，进入商店步骤（步骤 5，需至少 1 个村民） |
| `confirm-shop` | 将当前位置设为商店村民位置并立即生成 NPC（步骤 6，**必填**；设置后停留本步可覆盖/清除） |
| `showshopparticles` | 金色粒子预览商店位置（步骤 6，未设置时提示） |
| `clear-shop` | 清除本竞技场的商店位置与 NPC（步骤 6；清除后留在本步，对局中拒绝） |
| `preview` | 打开配置预览 GUI（步骤 7；spawn/村民/商店缺项会被拒绝并跳回补齐） |
| `goto <步骤>` | 跳转到指定步骤（1-8） |

## 步骤说明补充

> 步骤 3 部署两套独立坐标：先走到玩家出生点位置点击 [添加当前位置]（反馈为"生成点 #N 已添加"），再走到怪物刷怪点位置点击 [添加刷怪点]（反馈为"怪物刷怪点 #N 已添加"）。[打开生成点总览] 打开第 3 步枢纽界面：两套点的计数与配置状态一览，并可进入两个子管理界面（54 格 GUI，每页 45 个，各自带 [返回总览]）。唯一 [完成] 按钮在总览内（两套点都配好时显示绿色）——两套点各至少 1 个才能离开本步。
> 步骤 4 说明能量节点 = 世界中放置的重生锚：**走到锚旁边点击 [添加节点] 手动注册**（必须至少 1 个；0 节点开局后全员无法复活；当场上最后一个存活玩家阵亡时（无存活玩家且无活跃节点）全队判负）。[打开节点管理] GUI 可查看/删除已注册节点。
> 步骤 5 村民为**失败条件**：全部阵亡即游戏失败，请至少放置 1 个。走位点击 [添加村民] 记录，[打开村民管理] 核对，[完成] 进入下一步。
> 步骤 6 商店位置为**必填**：完成部署前必须设置商店村民位置。走到目标位置点 [设置商店位置]（设置后停留本步可覆盖 / 清除）；点 [清除商店位置] 删除重来（清除后留在本步），准备好后点 [继续] 进入预览。商店村民位置按竞技场持久化在 `arenas.yml` 的 `arenas.<id>.shop-npc` 节点，服务器重启后自动恢复；插件启动时会自动清理残留的重复商店村民实体。`/hilltop deploy setshop` / `/hilltop deploy clearshop` 与 `/hilltop manage` 详情页右键商店条目提供同样的设置 / 清除入口（清除对局中拒绝，需先 `stop`）。
> `/hilltop start` 前置校验：游戏已在进行中会提示先 stop；人数不足 min-players 会明确提示当前/所需人数，不再静默失败。

## 竞技场世界准入保护

> **准入保护**：竞技场世界有传送准入保护——未加入对局的玩家无法用 `/tp`、`/execute in` 等外部手段传送进入竞技场世界（会提示"你还没有加入本竞技场"）；管理员豁免（便于部署），`/hilltop join` 正常加入不受影响。
